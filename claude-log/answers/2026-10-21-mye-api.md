# Does Amazon have an API for Manage Your Experiments? (2026-10-21)
You asked: does Amazon have an API for Manage Your Experiments (MYE)?
Type: research (existence question).

## Answer
Not found. No Amazon API for MYE appears in the official Selling Partner API (SP-API) model list, and no Amazon page about MYE mentions one. Amazon has not been shown to say "no API exists"; this is "not found", not "does not exist".

## Evidence (opened this session)
- SP-API models page (developer-docs.amazon/sp-api/docs/sp-api-models), read in full (chars 0-131388): 56 sections incl. A+ Content, Listings Items, Reports, Data Kiosk, Customer Feedback; none named experiments / A/B test. Primary source. Undated.
- GitHub amzn/selling-partner-api-models /models directory (55 folders listed; page said "View all files", so list may be partial): none about experiments. Primary source. Undated.
- Amazon blog sell.amazon.com/blog/manage-your-experiments (2024-03-12): silent on API; describes only in-tool automation (auto start, auto end on winner, auto-publish winner, weekly result refresh). Primary.
- Amazon tool page sell.amazon.com/tools/manage-your-experiments (footer 2026): silent on API. Primary.
- SellerLabs guide: silent on API; manual Seller Central clicks only. Secondary.

## Contradicting evidence
None found. Searches aimed at "no API" / "automation endpoint" / third-party integrations returned only UI guides and unrelated vendors (Alexa SMAPI A/B testing API, AWS CloudWatch Evidently, AppConfig, Optimizely). The Alexa A/B Testing API is a different product (skills), not listings; snippet only, unopened.

## What exists instead (inferred)
MYE is a Seller Central / Vendor Central UI tool (Brands > Manage Experiments). Automation Amazon does offer is inside the tool. Related APIs that exist: A+ Content API, Listings Items API (can change content, so a self-run split test is possible but is not MYE).

## Confidence
Medium-high that no public MYE API is documented: two primary sources (SP-API model list, GitHub models repo) agree, plus three Amazon/seller pages silent. Not high: absence in docs cannot show absence of a private/partner-only API, and the GitHub list may be truncated.

## Not verified
- Whether Amazon Ads, Vendor Central, or a partner-only program exposes MYE data. Not searched on Amazon Ads docs.
- Whether the Amazon Selling Partner connector for Claude (beta, Sept 2026) exposes experiments; tool list not opened.

## Stopping
Searches 5 and 6 (export/integration, extended SP-API/GitHub) added no new independent source: stopped on saturation.
